# Controle Financeiro Laravel

Sistema web para gerenciamento de receitas, despesas, categorias e metas financeiras.

## Funcionalidades

- Cadastro e autenticação de usuários
- Controle de receitas
- Controle de despesas
- Gerenciamento de categorias
- Definição de metas financeiras

## Tecnologias

- PHP 8
- Laravel
- MySQL
- Blade
- Bootstrap

## Instalação

```bash
git clone ...
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
